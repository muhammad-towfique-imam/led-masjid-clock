# REQUIRMENTS #

Run the following command before working on the project

```
pip install tkcalendar
pip install hijri_converter
pip install bangladatetime
pip install bs4
pip install lxml
pip install auto-py-to-exe
```

# GENERATE EXE #

Fix path in `auto-py-to-exe-settings.json` and load the file in auto-py-to-exe program and generate exe using it
